# ADR 0002 — Python 3.12 com pip

## Estado

Aceito.

## Decisão

O projeto usa Python 3.12 e instala todas as dependências de `requirements.txt` com `pip`. O arquivo `.python-version` indica a versão aos gerenciadores de Python que o reconhecem, e a aplicação recusa outra versão em tempo de execução. Não há lockfile.
