artefatos de projeto; não existe frontend implementado nesta sprint. A API pode
ser usada na documentação interativa `/docs`.

| Tela | Caso de uso | Wireframe |
| --- | --- | --- |
| TL01 | UC01 — cadastrar usuário | [Cadastro de usuário](TL01-cadastrar-usuario.md) |

autorização, aplicativo ou validações que a API ainda não possui.
